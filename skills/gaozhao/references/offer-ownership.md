# 钱、编制、审批、锅

内部卡住时，先画四格。空一格，后面全是替位。

| 位置 | 必须有人署名 | 缺了会怎样 |
|---|---|---|
| 谁出钱 | 预算主人 | 高价没有合法的家 |
| 谁定级 | 序列主人 + 薪酬口径 | 岗位名还是低档，倒挂算式不改 |
| 谁审批 | 薪酬 / 规则主人 | 他签的是规则，不是人情 |
| 谁承担后果 | 必须跟编制**和日常被看见的线**走 | 人在 A 干活、听 B 的，倒挂砸在被看见的那边 |

编制挂在中台、人在项目用——「谁出钱」和「谁被比较」可以不是一回事。薪酬卡的是后者。

## 两种高价，不是一回事

| | 补差 | 整包 |
|---|---|---|
| 结构 | 项目/原岗该有的价 + 超出部分别处补 | 整包就是这个序列这个岗的价 |
| 比较基准 | 还是原岗同事 | 新序列里已经拿这个价的人 |
| 薪酬签的是 | 破例、口子、可复制 | 对标先例，不倒挂 |
| 同事看见的 | 这个人比我们贵一截，公司补的 | 他不是我们这档 |

「编制已经在中台、超出部分公司承担、不让项目出」——在薪酬眼里仍是补差：岗位还是那档，只是账单改了。他已经说过的那种结构：主要不是谁承担费用；别处出一部分，倒挂也还在。

中台序列里已经有同价的人，这条本该最好签。还不签，说明这个价在他眼里还不是「那些人的价」，是「项目价上面叠补贴」。

## 为什么薪酬不替你说「编制挂中台 / 超出中台承担」

那句话是**认领**，不是指示。指示可以从薪酬嘴里出来，认领只能从主人嘴里出来。薪酬一说：

- 越权（编制是组织动作）
- 变成假结构的作者（对方点头即可，人照样给项目用）
- 把一个主人没要的高价人塞进别人序列

所以他要主人自己开口，而且必须是整包，不能是「差额我出」。开口本身才是答案。被喂了再说，是配合演出。

薪酬排除招聘、只要预算主人来谈，不是针对 HR：他在换**提案人**。招聘会 + 加上主人 = 主人可以只点头出钱。只有主人来，他必须自己答：汇报给谁、OKR 挂哪、倒挂爆了谁接。

## 招聘不该做的

不要当预算主人和薪酬之间的调解人。

你冲上去「说服薪酬」，等于同时替业务和薪酬做担保。任何一边不满意都回到你。

你的产出停在两样，交给主人让他带进门：

1. **四件事填空**：编制 / 汇报 / 考核 / 日常管理——要高价成立，四格都要落在同一个比较基准上；项目只写借用边界
2. **一句口径**：这个价装的是哪一档岗名；装不进去就不要硬批

会后只认书面回流。口头「聊过了、也同意了」等于没有。含糊 = 不认领。

## 愿意出钱 ≠ 愿意当主人

预算主人可以乐意「为某块能力溢价买单」，同时不想跟项目去盘日常怎么用。出钱止于签字，不含跟进、不含背锅。

挂名在他的组织 + 真主人缺席 = 和「只有 HR、没有主人」同一结构。钱从 A 走，人在 B 用，倒挂仍砸在 B。

测的不是「你愿不愿意出这个价」，是：

1. 这个人汇报给你吗？
2. OKR 挂你，还是挂项目交付？
3. 薪酬那边，你去谈？

含糊时默认：这是补贴，不是认领。不要激发他的热情去填所有权空位——那是又一次替位。

## 升级

钱、编制、先例都在，薪酬仍否——卡点往往不在钱，在「这个决定谁说了算」。出口是主人与薪酬走到共同上级，招聘提前把一页证据和四格结构放到主人手里，而不是自己去升级。
