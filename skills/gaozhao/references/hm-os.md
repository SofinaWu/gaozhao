# 用人方操作系统

在「怎么招」之前，先判断**这个人能给什么、不能给什么**。配错类型，好人也会变成下一篇离职长文。

## 先分型，再配人

制作人 / 项目负责人常见两型，不要混：

| | 创意制作人 | 选择者（执行监工） |
|---|---|---|
| 能给的 | 北、判断、为什么做这个 | 流程、细节、拍板、节奏 |
| 给不了的 | 有时给不了清晰流程 | 意义、fully context、安全感、培养 |
| 自我认同 | 我来定方向 | **我来选** |
| 人走了 | 能力在人身上，会痛 | 库存丢了，去市场上补 |

选择者的结构：**空的是生成，满的是选择权。**  
不授权、不给 context，在他主观里常常是：这不是你的事，锅别过户给你。在执行者那边，体验是不信任。两边可以同时为真。

证伪「他是在保护」：失败时锅停在谁身上。若成功归他拍板、失败追执行——那是选择权不对称，不是情义。

## 他若说缺两种人

典型口吻：要一个「点子库」（供他选），要一个「能冲的管家」（往前推）。

翻译：他自己不是那两种人，又不肯把章交出去。

| 他要的功能 | 没有真权时实际变成 | 该招的 |
|---|---|---|
| 点子库 | 货架；说了没用 | 能批量出方案、不需要被认同的供应者——或先写清「谁来关建议」再招高创作欲的人 |
| 大管家 / 强 PM | 催办；队列送到他桌上 | 说不清「哪些可以不经他改判」就不要招 ENTJ 型。章在他那儿，加人不能提效 |

**卡点在章，不在缺 PM。** 所有节点回流同一个人，再强的执行也只是把队列送得更勤。吞吐量 = 他的审批带宽。

## 「人不可能成长 / 用一时」

把项目周期写成了人的本质。操作后果：

- 不投资解释、培养、留存
- 人被挖 → 当失窃 → 查周界、要求去对手仓补货
- 潜力、成长空间他听不见；只收「现在就是这个功能」

招聘侧：不卖成长。岗位话术停在这一期的功能。

## 提前背调 + 赔偿金秒否

他不是在选能力，是在排雷。

- 简历一到手就问一圈 = 评价外包（圈里人怎么说、上一家怎么处置）
- 赔偿金 / 优化 / N+X = 出清章，盖过名项目
- 主动离职、在职 = 流通货；领包走 = 退货，不必打开看
- 连聊都不聊 = 拒绝用情境拯救标签

名字进他手 = 圈内曝光，不可逆。

**不要教育「赔偿金不等于差」。** 他不吃情境。过不了这扇门的人，走别的买家。

## 沉默当情

圈内情义（自己人、担当、不说、用扛来证明）和圈外库存（简历、功能、用完就换）可以是同一套道德、不同半径。

跟他，别控诉「你不信任人」——他听成否认他在扛。  
能用的是逼出**边界清单**：哪些事你真的扛、失败算你；哪些他们可以定、你不改判。写得出来，沉默才是划界；写不出来，按瓶颈配人。

不要替他向团队翻译「他是为你好」。团队过的是没权、没解释、出事被追。那是真实体验。

## 配人原则

1. 他给不了北 → 班子里要另有供能的人（主策 / 能把为什么说清的人），或只招不需要被点燃的执行
2. 他不交章 → 不要用「提效」包装加人
3. 他排雷 → 漏斗只收流通货；退货去别的买家
4. 需要意义、解释权、成长空间的人，安检过了也不推给他
