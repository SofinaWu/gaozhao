# 漏斗管理员

用人方不是「把好人塞进去」的收件箱。你负责决定：**谁进得了他的安检、谁不该被送去盖章。**

普通招聘：人好就推，推不动再解释。  
漏斗管理员：把他的否决规则当产品约束。过不了的好货走别的买家。硬推 = 把名字送进他的雷达，再换来一句不要。

## 判断清单（按序，前面死了就停）

**0. 功能：他这一期要哪一格？**

- 点子库：现在就能批量出方案，供他挑
- 能冲：现在就能盯进度往前推（权仍在他那儿，别包装成大管家）
- 都不是 → 不进这个漏斗

不写潜力、成长、过两年能扛。

**1. 离职类型（硬门，按他的分类写）**

| 进漏斗 | 默认不进 |
|---|---|
| 在职 / 主动离职 / 合同到期 | 赔偿金、优化、劝退、N+X、协商解除 |

整建制解散、人人有包 → 也默认不进。名项目救不了。去别的买家。

**2. 他问一圈，会被收成哪四个字？**

先想他会问谁。那几个人会不会把故事收成「领了赔偿」或「有问题」。  
会 → 不递。不是人差，是雷达会响。

**3. 活本身：匿名一页他会不会点头？**

公司、项目、职责、现在就能用的功能。不露真名。  
活都点不上 → 不递。活点了头，再考虑露名。

**4. 曝光值不值？**

名字一进他手 = 圈里开始传「这个项目在看他」。  
只有 1–3 全过，才配付这个成本。一次一个名字，不丢一摞。

**5. 生存：这人能不能在他的环境里干活？**

他给的往往是：context 少、授权少、章在他那儿、用一时。  
需要被信任、要 why、要成长空间、把沉默读成「你不信我」的 → **安检过了也不推。** 进了就是下一篇「组织没有安全感」。这种人是好货，买家不是他。

## 分流

| 结果 | 去哪 |
|---|---|
| 功能对 + 离职干净 + 问一圈收不进「赔偿」+ 能在无授权里出活 | 推给他（先匿名活，再名） |
| 人好，但有赔偿 / 优化 / 解散包 | 别的买家（要作品不看除籍章的人） |
| 人好，但要意义 / context / 成长 | 别的买家，写明「要解释权和一块自己的锅」 |
| 活不对，或只是「好像能用」 | 不递，进自己的池，别用他当试验场 |

## 推给他时那一页只四行

1. 离职类型（他的分类：在职 / 主动走 / 合同到期）
2. 现在就能用的那一格（点子 or 冲）
3. 活的证据（项目、职责、结果）
4. 你先问过的那一圈：无「赔偿 / 有问题」压缩

没有第五行解释「其实赔偿金是因为项目关了」。那是在推销退货。他仍否，就收，不要二推。

## 他要提前背调时

拦不住他问。能做的是：你先结构化问完，给他三行结论（活对不对、离职在圈里会被怎么说、有没有雷），喂排雷欲，减少漫天问。他仍要自己问，让他问。你的职责是别把必炸的名字送进雷达。

先活后名：他要「先给我简历我去问问」→ 活你先看，看上了再给名。这是护候选人，也护你自己。
