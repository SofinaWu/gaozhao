# 第 2 步 · 寻源

## 目标与完成标准

竞品分析、行业调研、情报收集是寻源的原料；寻源的终点是**具体的人**。情报帮你看懂外面，寻源负责落到人。

| 层 | 做什么 | 产出 |
|---|---|---|
| 1 情报 | 看懂外部：竞品动态、人才地图、行业大会、公开分享 | 地图、判断、假设 |
| 2 定位 | 找到哪个团队、哪个人在做你关心的事 | 目标团队与具体的人，附公开证据 |
| 3 落成名单 | 找到联系方式，标好证据，交给第 3 步 | 名单或样本 |

只做到第 1 层，没有落到人，第 2 步不算走完。

两条线的终点不同：
- **岗位线**：一批能拿去换反馈的**样本**，而不是一份按自拟画像拉的名单。完成标准：用人方对样本给出了具体的「要 / 不要 + 为什么」
- **行业交流线**：做过这件事的人，附公开成果作证据。完成标准：能说清楚他做过什么、与一号位关心的问题对得上在哪

## 判断点
| 信号 | 走向 |
|---|---|
| 只有学校、公司、职级、项目等标签 | 用于召回和形成假设，不直接形成候选人结论 |
| 拿到很多零散信息，但说不清意味着什么 | 停止继续堆信息，先写「事实—假设—待验证」 |
| 硬门槛还没确认 | 只出候选清单，不对外触达（硬规则 2） |
| 「市场上没有」 | 先怀疑需求，用样本换需求 → `vuca-intake` 第 3 步 |
| 想在公开平台发岗 | 平台只用于找样本、测市场；主渠道是定向触达，见下方「渠道选择」（硬规则 4） |
| 想系统研究目标公司或竞品团队 | 先定目的，再看项目 / 组织 / 人才 / 时机四层 → [人才地图与竞品动态监测](../references/talent-map.md) |
| 竞品出现上线、重组、收缩等变化 | 作为重新研究的信号，不直接推断个人想离职 |
| 内部核心人才要离职 | 主动关心他去哪里；去向记入人才地图作为竞品信号，并保持联系 → [人才地图 · 内部核心人才的流向](../references/talent-map.md) |
| 遇到一个陌生领域，不知道从哪下手 | 先找这个领域的专家网络聊；没有就建一个，每个领域内外部合计 2–3 人 |
| 某领域只有一位专家在给判断 | 补到 2–3 人再下结论；一个人的口味容易变成隐含标准 |

## 模板
- **标签只负责召回**：学校 / 公司 / 职级 / 项目 / 地域
- **硬门槛负责过滤**：没有它就不能解决当前问题的技能与经验
- **属性与动机留到第 4–5 步验证**：不从标签直接推断「优秀」「稳定」「有潜力」
- **人才地图与动态预警**：[references/talent-map.md](../references/talent-map.md)
- 待补：样本反馈记录表

### 渠道选择：不只盯招聘平台

高招岗位的人，很多不在招聘平台上活跃。平台用来找样本、测市场（硬规则 4），主力渠道要主动开拓：

| 渠道 | 怎么用 | 适合 |
|---|---|---|
| 行业大会、论坛、线下沙龙 | 用 AI 检索今年本领域的会议和议程，挑讲者和参会团队对口的场次，到现场交流、换联系方式 | 一线实践者、技术专家；也适合补充行业交流线 |
| 公开分享与作品 | 大会演讲、论文、开源项目、技术博客、作品集 → 找作者 | 做过某件事、有证据的人 |
| 行业媒体与编辑 | 长期关注行业媒体公众号，看编辑对项目负责人的专访；找到对口的项目后，联系写这篇专访的编辑，请他帮忙引荐或给到联系方式 | 项目负责人、制作人等平台上几乎找不到的人；也适合行业交流线 |
| 内部对外岗位的同事 | 找公司里天天和行业打交道的人，比如商务负责人、大客户管理负责人（平台、发行、渠道业务尤其多），请他们引荐熟悉的项目负责人和行业大佬 | 项目负责人、公司高层等需要熟人引荐才见得到的人；尤其适合行业交流线 |
| 领域专家网络 | 找内部和外部专家推荐他们认可的同行 | 圈内口碑好、平台上找不到的人 |
| 猎头 | 给清楚的硬门槛，让猎头定向寻访；平时长期维护关系（见下） | 时间紧、需要大范围扫描时；也会主动推荐平台上找不到的人 |
| 招聘平台 | 找样本、测市场；不当主路径 | 了解供给和薪酬水平 |

**线下活动前后要做的事**：
- 会前：看议程和讲者名单，标出 3–5 个想认识的人，想好每人一句和他工作相关的开场。
- 会上：先聊他的分享和工作，不先递岗位（第 4 步「先问他，再讲 JD」）。
- 会后 48 小时内：跟进联系，记下当时聊了什么、他关心什么；归入岗位线或行业交流线。

**猎头关系要平时养，不是有岗才找**：
- 定期请本领域的猎头来公司吃饭、交流，让他们了解公司在做什么、需要什么样的人。
- 节假日寄礼品，保持联系。
- 好猎头会在没有正式需求时，主动推荐重量级的人。收到推荐要及时反馈结果，不让推荐石沉大海。
- 合作边界：推荐费按合同；不通过猎头打听候选人所在公司的机密。

**行业媒体编辑也要长期维护**：
- 专访本身就是情报：项目做到哪一步、负责人怎么想、团队缺什么，都能从中读出来。
- 编辑认识的项目负责人多，是可以长期合作的引荐人，不是一次性拿联系方式的工具。平时可以给他们提供行业交流、选题线索，互相有来有往。
- 请编辑引荐时，说明来意，并尊重对方的意愿：编辑或负责人不愿意，就不勉强。
- 编辑给的联系方式只用于这次说明过的来意，不转给别人。

**请内部对外岗位的同事引荐时**：
- 他们的客户关系是业务资产。先说清楚来意（行业交流还是招聘），由他判断合不合适、怎么介绍。
- 不能影响他和客户的合作：对方是合作方、客户时，不以挖人开场，优先走行业交流线。
- 聊完把结果同步给引荐的同事，不让他在客户面前被动。

### 情报碎片账

| 事实（原始信息） | 当前假设 | 其他可能解释 | 下一条最省力的验证 |
|---|---|---|---|
| 只写看到 / 听到的，不解释 | 这条信息可能意味着什么 | 至少保留一个竞争解释 | 一个问题、一个样本或一个旁证 |

碎片越多，不代表判断越准。没有形成可验证假设的信息，只是库存。

### 领域专家网络

每个关键领域，找到 **2–3 位**你亲自聊过、确认很强的专家。之后遇到这个领域的事，第一时间找他们。

| | 内部专家 | 外部专家 |
|---|---|---|
| 是谁 | 公司内部公认在这个领域长期稳定产出的人 | 外部聊下来很强的候选人，作为顾问保持联系 |
| 需求澄清 | 判断岗位真正要什么、哪些是硬门槛 | 告诉你市场上做到什么水平算强 |
| 寻源 | 推荐他认可的同行 | 告诉你谁真正做过、哪些团队强 |
| 评估 | 参加专业面，校准判断 | 侧面了解这个领域的真实水平 |
| 行业交流线 | 陪一号位交流，把关专业深度 | 本身就可以是交流对象 |

**台账字段**：领域 / 专家（内部或外部）/ 擅长判断什么 / 怎么认识的 / 上次交流时间 / 他给过的判断和后来的结果。

**规则**：
- **每个领域 2–3 人，不靠一个人下判断**。意见不一致时，分歧本身就是信息。
- **警惕专家的圈子和来源环境**：他推荐的人通常和他相似；他的标准可能来自上一家公司。
- **外部专家要有来有往**：给真实价值，比如交流、认可，必要时付顾问费，不长期免费索取。不向他透露公司内部信息，也不打听他所在公司的机密。
- **定期对账**：专家判断过、推荐过的人后来表现如何？长期不准的，换掉。
- **真实姓名只记在本地人才库**，不写进本 skill。
