# 第 4 步 · 动机核实（强制）

## 目标与完成标准
- 说得清「他为什么走 / 为什么动」，并有证据
- 说得清他在当前职业阶段想完成什么变化
- 完成标准：动机与约束写进评估，且标明哪些是他说的、哪些是你推断的

## 判断点
| 信号 | 走向 |
|---|---|
| 一开口就讲我们的 JD，或打算到面试里再问期待 | 停下。第一次接触时就先问他「期待下一份工作长什么样」；面试中再问，答案已被岗位和面试内容影响 |
| 只有「看机会」「想换环境」 | 未完成，继续核实；渠道（电话 / 微信 / 面谈）自选，这一步不能省（硬规则 5） |
| 只有离开上一家的原因，没有下一阶段要去哪里 | 未完成；继续问他期待下一份工作带来什么变化 |
| 动机与岗位真实难点对不上 | 留存风险，写进第 5 步的「风险与待验证」 |
| 离职类型是赔偿 / 优化 / 协商解除 | 记录实际背景，按第 6 步核对当前岗位相关影响；不把离职标签或历史负责人的偏好当通用否决条件 |

### 初识冷淡，先保留观察并持续链接

初识时回应少、态度冷淡或回答模糊，不代表这个人不值得链接，也不足以判断他的职业动机、能力或长期关系价值。先保留观察，区分已知事实与自己对其态度的解释。

如果已有具体依据认为对方与你关注的主题相关、能带来重要信息、实践判断或资源增量，就持续跟进、保持联系；不因一次弱回应直接放弃。结合新的公开分享、共同问题或有价值的信息，找到合适的再次交流契机，让双方逐渐看见彼此的价值，而非重复发送同一请求。

当前不看岗位与不愿保持关系分别记录，联系节奏结合对方反馈调整；明确要求不再联系时，停止主动联系及跟进提醒，不换渠道或请同事联系。持续跟进是有依据、有新内容的关系投入，不把冷淡自动解释为默许，也不因拒绝岗位自动安排季度跟进。具体分支见 [第 3 步](03-engage.md)，案例见 [从弱回应到年度关键链接人](../cases/03-从弱回应到年度关键链接人.md)。

## 模板
- 深挖动机：见 `talent-read`「深挖动机」

### 先问他，再讲 JD（核心标准）

不是拿着 JD 去告诉对方「我们有个岗位」，而是**在第一次接触时、讲 JD 和进面试之前，就先问他期待下一份工作长什么样**。

**为什么必须一开始就问**：等到面试中途再问，他已经听过岗位和面试内容，会不自觉地按你们的需要调整答案。那时候听到的，已经不是他真实的想法。第一次问到的答案是他最原始的期待，后面所有判断都拿它做基线。

**到 offer 阶段还会再用上**：他手上有好几个 offer 时，最后让他摇摆的，往往就是第一次说的那些初心。这份原话就是第 7 步帮他做决定的依据。

- 开场问：「如果下一份工作让你很满意，它大概是什么样子？做什么事、和什么人、在什么环境里？」
- 先听，记原话并标注日期；不急着把他的回答往 JD 上套。
- 后续面试中他的说法如果变了，对照第一次的原话：变化是信息变多后的真实调整，还是在迎合岗位？
- 听完再对照：哪些对得上，哪些对不上。对不上的要如实说，不靠话术弥补。
- 顺序反了的后果：先讲 JD，对方会顺着岗位描述自己，你听到的是迎合，不是他真正想要的。

### 问清下一份工作的期待：想得到什么、摆脱什么、证明什么、走向什么角色

> 不直接问抽象的「人生目标」。从他正在做的取舍里判断，并区分原话与推断。

1. **想得到什么**：更难的问题、决策权、资源、收入还是影响力？
2. **想摆脱什么**：天花板、组织限制、重复劳动，还是不认可的方向？
3. **想证明什么**：能做一号位、能从技术走业务，还是能独立从 0 到 1？
4. **想走向什么角色**：专家、管理者、创业者，还是某一领域的定义者？

输出一句话：

> 他希望下一份工作带来的变化是 `<想完成的变化>`；证据是 `<具体选择或原话>`；这个岗位能 / 不能提供 `<对应条件>`。

### 找他的「专长」

真正难以替代的能力，往往长在他自发投入的地方，而不是简历标题上。

- 没人要求时，他自己在钻研什么？
- 什么事对他像在玩，对别人却像在工作？
- 他聊起什么会主动展开细节、停不下来？

专长和岗位真实难点重合，动机和留存都更稳；完全不重合，记为第 5 步的风险。

### 对方决策模型

不要满足于多知道一条个人信息。要试着还原他做职业决定时的排序方式：

1. 他把什么当收益，什么当损失？
2. 哪种代价是他绝不接受的？
3. 什么条件一出现，他会改变决定？
4. 过去两次重要选择，是否使用了同一套排序？

每次只用一个问题验证一个假设。对不上就改模型，不把「我猜他是这种人」当结论。
