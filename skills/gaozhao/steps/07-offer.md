# 第 7 步 · Offer 与内部结构

## 目标与完成标准
- 钱、定级、审批、后果四格都有署名的主人
- 完成标准：主人自己带着证据和口径去谈，会后有书面回流

## 判断点
| 信号 | 走向 |
|---|---|
| 四格有空位 | 先补主人，不推进审批 |
| 编制在 A、人在 B 用 | 核对当前制度下的编制、汇报、考核与日常管理；区分补差与整包，确认各自审批条件，不预设只有一种结构能获批 |
| 自己正在「说服薪酬」 | 停下，你在当调解人（硬规则 6） |
| 钱、编制、先例都在，仍被否 | 先核对实际否决理由与审批条件；确认是权限或跨部门分歧时，由负责该事项的人按当前流程升级，不直接推定卡点或由招聘代拍板 |
| 合作只靠口头承诺或单纯加钱维系 | 补成书面约定：谁兑现、何时验证、不兑现怎么办；纯利益绑定在力量变化时最容易破 |
| 候选人手上有多个 offer、在摇摆 | 对照第 4 步的最初原话并核实最新期待，再一起比较各个 offer；允许优先级变化。别家更符合其当前需要时，如实说，不靠加钱硬拉 |
