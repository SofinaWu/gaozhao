# 第 7 步 · Offer 与内部结构

## 目标与完成标准
- 钱、定级、审批、后果四格都有署名的主人
- 完成标准：主人自己带着证据和口径去谈，会后有书面回流

## 判断点
| 信号 | 走向 |
|---|---|
| 四格有空位 | 先补主人，不推进审批 |
| 编制在 A、人在 B 用 | 识别是补差还是整包 |
| 自己正在「说服薪酬」 | 停下，你在当调解人（硬规则 6） |
| 钱、编制、先例都在，仍被否 | 卡点是决定权；由主人走共同上级，不由招聘升级 |
| 合作只靠口头承诺或单纯加钱维系 | 补成书面约定：谁兑现、何时验证、不兑现怎么办；纯利益绑定在力量变化时最容易破 |
| 候选人手上有多个 offer、在摇摆 | 拿出第 4 步记下的初心原话，和他一起逐条对照各个 offer；摇摆点往往就在初心里。别家更符合他的初心时，如实说，不靠加钱硬拉 |
