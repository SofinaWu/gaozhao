# 接触与建立关系

> **你争取的不是对方的时间，是他的注意力。**
> 好的人不缺机会，缺的是值得花注意力的对话。

**先看已表达的联系边界。** 明确要求不再联系的人，停止主动联系及季度跟进提醒；不以行业分享、换渠道或请同事联系绕过。拒绝当前岗位不等于拒绝所有交流，回应少也不等于同意持续联系。已知边界优先于下面的开场准备和长期关系节奏。

## 第 0 步 · 先定位他的高优先级需求（做不到这步，后面全是话术）

> **你能解决他高优先级需求的程度，决定你能给他多大价值。**

接触前必须先有一个假设：**这个人当下真正在解的是什么题？**

### 三个入口（都拿不到就别急着联系）

1. **从痛入手，不从需求入手。** 对方不一定知道自己要什么，但一定知道自己的痛
2. **看资源流向。** 他的时间和精力花在哪——说出来的优先级会撒谎，资源分配不会
3. **从公开产出反推。** 他最近做了什么、发了什么、组织有什么变动、他在什么阶段介入的

### 候选人的高优先级需求，常见的不是钱

| 高优先级需求 | 观察线索 | 你能给的 |
|---|---|---|
| 想解一个更难的题 | 反复提技术/业务难点，不提待遇 | 说清这个岗位真正难在哪（别美化） |
| 想验证一个判断 | 有强观点，想找地方落地 | 告诉他哪里的土壤适合这个判断 |
| 卡在天花板 | 讲组织限制、决策链、拿不到资源 | 组织位置与授权范围的真实信息 |
| 需要安全感（有约束条件） | 谨慎、反复确认稳定性 | 明确的边界与真实的风险披露 |
| 想被看见 / 换标签 | 在意 title、在意做什么被记住 | 视野与定位建议 |
| 阶段性不动（vesting / 项目未结束） | 明确说"现在不合适" | 停止推进当前岗位；后续交流按对方意愿和约定，不自动转为季度跟进 |

### 三个层级，价值差一个数量级

| 层级 | 你做的事 | 可替代性 |
|---|---|---|
| 解决 | 直接给到他要的（如一个真的匹配的机会） | 高 |
| 推进 | 让他离解决近一步（信息、连接、视野） | 中 |
| **重新定义** | **让他发现自己排错了序**（例：他以为要换公司，其实要换的是问题类型） | **几乎不可替代** |

第三层前提：**有证据不是有观点**，且**你已经先给过实际价值**。没有交付记录就点评别人的职业选择 = 越界。

### 反向：早说你不能解决什么

不能给的早说，是信任的来源。
「这个岗位现在给不到你要的授权范围」比含糊过去强一百倍。**不能解决却含糊，是最贵的一种不专业。**

## 第 1 步 · 首次接触

### 开场三件事（顺序不能换）

1. **先说身份。** 你是谁、代表谁、为什么联系。**身份必须前置披露**——先建私交后暴露商业身份，等于钓，一旦被察觉信任归零
2. **再说为什么是他。** 具体到他做过的某件事。「看到您的简历很优秀」= 群发，直接失效
3. **最后才说岗位（如果有）。** 并且明确说清「这次不一定为了这个岗位」——降低防御，而且这是真话

### 对方为什么不挂你电话（真实反馈，四条）

来自一个"平时接的猎头电话太多了，听到招聘都是秒挂"的人最终入职后的复盘：

1. **快速突出重点和优势** → 迅速建立信任
2. **需求与个人匹配度高**，聊的时候感觉自己的能力用得上 → 精准匹配
3. **沟通氛围平衡**——"没有特别 diao 的样子让人赶紧舔，也没有特别急迫的样子让人赶紧来" → 文化契合
4. **节奏适中，让人选自己有自由度** → 节奏感

第 3、4 条最容易被忽略，也最难伪装。

### 主动表达，先打开自己

**不懂就问，不怕犯错。暴露自己的不懂是一种交底行为，是信任建立的关键。**

- 不懂他的技术细节 → 直说，请他讲，认真听。比装懂强一百倍
- 对岗位本身的不确定 → 在不违约范围内可以说。「这个岗位方向还在收敛，我现在的理解是 X」比编一个确定画像更能获得尊重
- **先说你自己的判断，他才会说他的**

### 首次接触的成功标准

**他愿意有下一次。** 不是他答应面试。

## 第 2 步 · 自查：我是不是成了狗皮膏药

同样的动作，专业与 low 的分界在这四道题。**任何一道不过关就停手。**

### 主判别器：是否逐笔结算 + 长期流向

先看你会不会把刚给出去的一点价值，马上兑换成对方的时间、信息或配合；再看这段关系长期是不是有来有往。

| 互动模式 | 性质 | 处理 |
|---|---|---|
| 刚送出就立刻索取 | 隐形账单 | 停下来：这次给予必须先能独立成立 |
| 不预设单次回报 | 互惠的起点 | 允许回报延后、换一种形式，不逐笔标价 |
| 长期持续单向索取 | 不是互惠 | 停止供给，不用「长期主义」合理化失衡 |

> **先看见对方真正需要什么，能帮就真帮；不急着马上要回报，也不在心里逐笔记账。人与人不必一件事一件事地结清，长期来看有来有往就够了。**
>
> 人情债不是错的机制，排序错了才是。信任之前拿一个小债让对方不好拒绝，是用债务替代信任；信任之后的互惠不要求即时、等价、逐笔偿还，但长期完全单向也不是互惠。

急迫感外溢不是礼貌问题，是**筹码贫乏的自我暴露**。

### 三道辅助测试

**1. 针对性测试** —— 热情的强度不传递诚意，针对性才传递诚意
同一套动作对名单上任何人都成立 → 对方收到的信息是"你是一个号码"。
> **过分热情恰恰证明了对方不特殊。**
自查：我说得出他做过的具体某件事吗？

**2. 成本对等测试** —— 真价值输出的特征是你先承担了不可回收的成本
转手自己用不上的东西、顺手的举动 = 零成本，不构成价值输出。
自查：我付出的成本，和我索取的（他的时间、信息、关系资本）对等吗？

**3. 假征询测试** —— 最好用的一道测谎题
> **如果对方说"不需要"，这个动作还继续吗？** 继续 → 那不是给他的，是给你自己的。

### 动作闭环

**失败结构**：动作 A 为了换 B 的机会，B 又为了 C——没有一个动作在自身层面上完成。
对方感受到的"得寸进尺"就是这个结构，不是某一次越界。

**正确结构**：每个动作独立成立。
自查：**如果这次之后再无下一步，我做的这件事对他还有意义吗？**

### 组织级失败

同事已接触过、已收到明确的 no，仍在推进 → 负面判断会归因到**公司**而非个人，且很难修复。
自查：接触前查过内部触达记录吗？对方给过的 no 记录了吗？

## 第 3 步 · 长期关系（真正的资产在这里）

优秀的人**大多当下不动**。所以产物不是这次转化，是**关系的存续**。

- 对方愿意保持交流时，结合共同话题和约定安排联系；季度分享、行业信息、关键节点问候只是可选方式，不因入池自动启动。明确停止联系时取消主动跟进。
- **每次接触前准备一条他真的不知道的信息。** 做不到就别联系——空手 touch 会消耗关系
- 记录：动机、职业规划、约束条件、下次该聊什么
- 对他的动态变化持续关注（换岗、项目上线、vesting 节点）

### 被拒绝后

先区分拒绝的范围，再决定下一步：

| 对方表达 | 下一步 |
|---|---|
| 明确要求以后不要联系 | 停止主动联系和跟进提醒，记录原话、日期与范围；不再发送“最后一次价值输出”，不换渠道或请同事联系。对方后来主动重新联系时，只在其新表达的范围内回应 |
| 只拒绝当前岗位或暂时不看机会 | 收尾当前岗位，不纠缠；是否保持其他交流取决于对方意愿及既有约定，不自动安排季度跟进 |
| 回应少、暂未回复，或拒绝范围不清 | 保留观察，区分已知与未知；有相关新内容时结合既有关系和反馈判断是否适合再次交流，不把沉默视为默许，也不凭冷淡否定人的价值 |

记录对方实际表达的原因；未说明就记未知。自己的解释标为待验证，不替对方编造“真实原因”，不为确认原因反复追问。

### 受托信息红线

候选人的动机、规划、约束、薪资都是**受托信息**。
不外传、**不用于压价或谈判施压**、不进对外材料。**破一次，圈子里就没了。**

## 前提：28 原则

> 把 80% 的时间花在 20% 的人身上，还是平均分给每个人？

**必须是前者。** 平均分配 = 每个人都没聊透 = 拿不到任何真实信息。

代价要认：大部分人只能得到标准流程对待。这不是不专业，是资源配置。
而且**选择性本身就是尊重**——它证明你判断过这个人值得。

## 量变产生质变

**聊 100 个人，找到 Top 20。** 前 30 个的作用不是找人，是**校准你自己的标尺**。
接触量断了，判断力会钝。

## 失败模式速查

| 失败模式 | 修正 |
|---|---|
| 不知道对方的高优先级需求就开口 | 回第 0 步 |
| 身份后置披露（先建私交后说来意） | 身份必须前置 |
| 首聊就推岗位 | 先说为什么是他 |
| 价值输出只是客套 | 每次准备一条他真不知道的信息 |
| 装懂 | 直接问，认真听 |
| 只在有岗位时联系 | 无岗位期的 touch 才是关系地基 |
| 急迫感外溢 | 急迫会让好人退 |
| 当天送出当天索取 | 让这次给予独立成立，不制造隐形账单 |
| 用长期主义合理化持续单向供给 | 不逐笔结算，但看长期流向；长期只有索取就停止供给 |
| 把对方的坦白当筹码 | 受托信息不外传、不压价 |
| 只做对方的优先级，不看自己的积累 | 定期问：这些接触累加起来指向我想成为的人吗？ |
