# 高招 · 1.0

给招聘同事和 HRBP 用的高端招聘方法论，分两种形态：

- **[高招1.0-完整版.md](高招1.0-完整版.md)**：给人通读的单文件版。
- **[skills/](skills/)**：给 AI 助手用的 skill 版，内容与完整版一致。

## 核心内容

- **两条线**：岗位线（把合适的人招进来）和行业交流线（让业务一号位持续接触外部做过这件事的人；只交流、不招聘也是完整结果）。
- **八条硬规则**：比如没有已确认的硬门槛不以岗位名义触达、核实「为什么动」是强制环节、不当业务和薪酬的调解人。
- **八个步骤**：需求澄清 → 寻源 → 触达 → 动机核实 → 评估分层 → 递给用人方 → Offer 与内部结构 → 复盘与沉淀。每一步分四层：目标与完成标准 / 判断点 / 模板 / 案例。判断点是核心。

## skill 怎么用

`skills/` 下有四个 skill：

| skill | 作用 |
|---|---|
| `gaozhao` | 入口：先定位卡在哪一步，再进对应步骤 |
| `vuca-intake` | 需求说不清时的需求澄清 |
| `star-engage` | 怎么让好的人愿意和你聊 |
| `talent-read` | 按属性读人、分层、与用人方校准 |

把这四个目录一起复制到 AI 助手的 skills 目录（例如项目里的 `.claude/skills/`），对它说「我在高招上卡住了」即可。四个目录要放在同一层，`gaozhao` 会按需调用另外三个。

## 说明

- 内容已去公司化：不含具体公司、项目和人名，换一家公司也能用。
- AI 只给清单、假设和动作建议；不确定的主观判断由人来做，不自动对外联系任何人。
- 版本变化见 [skills/gaozhao/CHANGELOG.md](skills/gaozhao/CHANGELOG.md)。
